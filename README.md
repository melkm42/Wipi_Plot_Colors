# Wipi_Plot_Colors

Shared color mappings.

## Installation

Clone the repo and install in editable mode:

```bash
git clone https://github.com/melkm42/Wipi_Plot_Colors.git
cd Wipi_Plot_Colors
pip install -e .
```

## Usage

```python
from wipi_plot_colors import pixie_colors

print(pixie_colors['Teal'])  # "#14D8FF"
```
